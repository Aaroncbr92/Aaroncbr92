## Informativos frente a programas

| | **Grafismo de informativos** | **Grafismo de programas** |
|---|---|---|
| **A qué sirve** | **A la información: explicar un dato** | **Al programa: darle carácter** |
| **Cuánto dura** | **Años: es un sistema estable** | **Una temporada** |
| **Quién lo hace** | **Se rellena una plantilla, a veces en directo** | **Se diseña pieza a pieza** |
| **Qué se valora** | **Legibilidad y neutralidad** | **Personalidad y recuerdo** |
| **Cuánto puede llamar** | **Lo justo: no debe competir con la noticia** | **Todo lo que el programa admita** |
| **Ritmo de producción** | **Minutos** | **Semanas** |

- **LA REGLA QUE RESUME LA TABLA**: **en informativos el grafismo desaparece y en programas se ve.**
  **Un rótulo de informativos bien hecho es el que nadie comenta.**
- **LA CONSECUENCIA DE MÉTODO, Y ES LO MÁS PREGUNTABLE**: **el de informativos se diseña como SISTEMA
  y el de programas como PIEZA.** **Lo primero que se entrega en informativos no es un rótulo: son las
  plantillas y sus reglas de uso**, porque quien las rellena a las tres de la tarde no es el
  diseñador.

| Elemento del sistema | Qué lleva |
|---|---|
| **Rótulo de identificación** | **Nombre y cargo de quien habla** |
| **Rótulo de tema** | **De qué va la pieza** |
| **Rótulo de última hora** | **La marca de urgencia, con su color propio** |
| **Cartela de datos** | **Cifras, mapas, gráficos** |

## Infografía

- **QUÉ ES, CON PRECISIÓN**: **la representación gráfica de información para que se entienda más
  deprisa que leyéndola.** **No es ilustrar una noticia: es explicarla.**

| Tipo | Qué muestra | Ejemplo |
|---|---|---|
| **De datos** | **Cifras y sus relaciones** | **Resultados electorales, presupuestos** |
| **De proceso** | **Cómo ocurre algo, paso a paso** | **Cómo se produjo un accidente** |
| **De situación** | **Dónde está algo** | **Mapas, plantas de un edificio** |

| Qué se quiere mostrar | Gráfico |
|---|---|
| **Comparar cantidades** | **Barras** |
| **Ver evolución en el tiempo** | **Líneas** |
| **Ver la composición de un total** | **Sectores**, y sólo con pocas categorías |
| **Ver relación entre dos variables** | **Dispersión** |
| **Ver distribución geográfica** | **Mapa de coropletas** |

- **LAS TRES REGLAS DE HONRADEZ**, que son lo más preguntable:
  1. **El eje de las cantidades empieza en cero.** **Cortarlo multiplica visualmente una diferencia
     pequeña.**
  2. **El área representa el dato, no el lado.** **Doblar un dato con el doble de diámetro enseña el
     cuádruple.**
  3. **La escala es la misma en todo el gráfico.** **Cambiarla a mitad de una serie es engañar.**
- **EL AVISO**: **una infografía se juzga por si el lector saca la conclusión correcta**, no por si es
  bonita.

## Interfaz y experiencia

| | **Interfaz de usuario** | **Experiencia de usuario** |
|---|---|---|
| **Qué es** | **Lo que se ve y se toca** | **Cómo resulta usarlo** |
| **Qué produce** | **Pantallas y componentes** | **Flujos, arquitectura de la información, pruebas** |
| **Cuándo se decide** | **Después** | **Antes** |
| **Se mide con** | **Consistencia visual** | **Tiempo de tarea, errores, abandono** |

- **LA FRASE QUE LAS SEPARA**: **la interfaz es el vestido y la experiencia es el viaje.** **Una
  interfaz preciosa sobre un flujo mal pensado da una mala experiencia**, y el usuario no sabe cuál de
  las dos le falló.

| Principio de usabilidad | Qué exige |
|---|---|
| **Visibilidad del estado** | **Que el sistema diga siempre qué pasa** |
| **Correspondencia con el mundo real** | **Que hable el idioma del usuario** |
| **Control y libertad** | **Que haya salida y deshacer** |
| **Consistencia** | **Que lo mismo se llame y se vea igual en todas partes** |
| **Prevención de errores** | **Que sea difícil equivocarse** |
| **Reconocer antes que recordar** | **Que las opciones estén a la vista** |

- **TRES CONCEPTOS QUE UN GRAFISTA DE TELEVISIÓN USA HOY**: **sistema de diseño** —el manual de
  identidad del tema 12 aplicado a producto digital—; **retícula adaptable** —la que reordena según el
  tamaño de pantalla—; **jerarquía visual** —la del tema 5, que aquí decide qué se pulsa primero—.

## Accesibilidad

| Requisito | Qué exige |
|---|---|
| **Contraste suficiente** | **Que el texto se lea sobre su fondo** |
| **No depender sólo del color** | **Que la información no se pierda si no se distinguen colores** |
| **Tamaño mínimo de texto** | **Que se lea sin ampliar** |
| **Alternativas textuales** | **Que las imágenes tengan descripción** |
| **Subtitulado y audiodescripción** | **En el material audiovisual** |

- **POR QUÉ ES OBLIGACIÓN Y NO BUENA VOLUNTAD**: **la ley general de comunicación audiovisual impone
  objetivos de accesibilidad al servicio público**, y **es materia del bloque común de esta misma
  oposición.**
- **EL REQUISITO QUE MÁS AFECTA AL GRAFISMO DIARIO ES EL CONTRASTE**: **un faldón gris claro con texto
  blanco es ilegible para mucha gente.**
