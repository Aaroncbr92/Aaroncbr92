# Familia de normas SMPTE ST 2110

Índice publicado por la propia SMPTE en su biblioteca abierta,
`https://pub.smpte.org/doc/2110/`, leído el 2 de septiembre de 2026.

Se guarda **el índice con los títulos oficiales**, que es lo que hace falta para
saber qué parte cubre qué. El texto completo de cada parte está en la misma
biblioteca, documento a documento.

| Documento | Título oficial |
|---|---|
| **OV 2110-0** | Professional Media Over Managed IP Networks — Roadmap for the 2110 Document Suite |
| **RP 2110-23** | Professional Media Over Managed IP Networks — Single Video Essence Transport over Multiple ST 2110-20 Streams |
| **RP 2110-24** | Professional Media Over Managed IP Networks — Special Considerations for Standard Definition Video Using SMPTE ST 2110-20 |
| **RP 2110-25** | Professional Media Over Managed IP Networks — Measurement Practices |
| **ST 2110-10** | Professional Media Over Managed IP Networks — System Timing and Definitions |
| **ST 2110-20** | Professional Media Over Managed IP Networks — Uncompressed Active Video |
| **ST 2110-21** | Professional Media Over Managed IP Networks — Traffic Shaping and Delivery Timing for Video |
| **ST 2110-22** | Professional Media Over Managed IP Networks — Constant Bit-Rate Compressed Video |
| **ST 2110-30** | Professional Media Over Managed IP Networks — PCM Digital Audio |
| **ST 2110-31** | Professional Media Over Managed IP Networks — AES3 Transparent Transport |
| **ST 2110-40** | Professional Media Over Managed IP Networks — SMPTE ST 291-1 Ancillary Data |
| **ST 2110-41** | Professional Media Over Managed IP Networks — Fast Metadata Framework |
| **ST 2110-43** | Professional Media Over Managed IP Networks — Timed Text Markup Language for Captions and Subtitles |

**Aviso que importa para el examen.** En esta familia **no existe una parte «ST 2110-50»**. Las partes publicadas son las de la tabla: 10, 20, 21, 22, 30, 31, 40, 41 y 43, más la hoja de ruta OV 2110-0 y las prácticas recomendadas RP 2110-23, 24 y 25.

Los **datos auxiliares** —*ancillary data*, la ST 291-1 embebida en el flujo— son la **parte 40**, publicada el **12 de abril de 2018**.
