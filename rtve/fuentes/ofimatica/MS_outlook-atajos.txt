 Métodos abreviados de teclado para Outlook
 Se aplica a Outlook para Microsoft 365 Outlook 2024 Outlook 2021 Outlook 2019 Outlook 2016 Outlook.com Nuevo Outlook para Windows Outlook para iOS Outlook en la web para Exchange Server 2016 Outlook en la web para Exchange Server 2019 Outlook Web App 
 Para muchos usuarios, usar un teclado externo con métodos abreviados de teclado para Outlook permite trabajar con mayor eficiencia. Los métodos abreviados de teclado pueden resultar más fáciles que una pantalla táctil y son una alternativa esencial al uso del ratón.
 Importante
 Los pasos pueden ser diferentes entre Outlook nuevo y clásico para Windows. Para determinar qué versión de Outlook está usando, busque Configuración en la cinta de opciones. Si no hay ninguna opción de Configuración , siga los pasos de la pestaña Outlook clásico . Si aparece la opción Configuración , seleccione la pestaña Nuevo Outlook .

 Outlook clásico 
 Outlook en la web 
 Nota
 Los métodos abreviados de teclado de este tema hacen referencia a la distribución del teclado de España. Es posible que las teclas de otras distribuciones no se correspondan exactamente con las teclas de un teclado de España.
 Un signo más (+) en un método abreviado de teclado significa que necesita presionar varias teclas al mismo tiempo.
 Un signo de coma (,) en un método abreviado de teclado significa que necesita presionar varias teclas en orden.
 En este artículo se describen los métodos abreviados de teclado en el nuevo Outlook para Windows. Aunque muchos de los métodos abreviados son los mismos que en Outlook clásico, existen algunas diferencias.
 Recomendación
 Para encontrar rápidamente un acceso directo en este artículo, presione Ctrl + +F y, después, escriba los términos de búsqueda.

 Soporte técnico del lector de pantalla para Outlook 
 En esta sección se describen los métodos abreviados de teclado de Outlook en la Web y Outlook.com.
 Nota
 En Outlook en la Web y Outlook.com, puede usar los métodos abreviados de teclado de Outlook.com, Yahoo Mail, Gmail o Outlook. En este artículo se describen los métodos abreviados de teclado disponibles si elige Outlook. Para obtener instrucciones sobre cómo cambiar la versión del acceso directo, vaya a Cambiar la versión de los métodos abreviados de teclado .
 Para encontrar rápidamente un método abreviado de teclado en este artículo, puede usar la Búsqueda. Presione Ctrl + +F y, después, escriba las palabras de búsqueda.
 La acción que realiza un método abreviado de teclado puede ser específica del área o la vista en la que está trabajando, a pesar de que incluya nombres de tecla y combinaciones de teclas conocidos.

 Cambiar la versión de los métodos abreviados de teclado
 En Outlook en la Web y Outlook.com, puede elegir qué métodos abreviados de teclado desea usar: Outlook.com, Yahoo Mail, Gmail o Outlook. Como alternativa, puede desactivar los métodos abreviados de teclado.
 Para ver una lista completa de los métodos abreviados de teclado que están disponibles en la versión que elija, presione Mayús + ? (Signo de interrogación)en el teclado.
 En Outlook.com y la nueva Outlook en la Web, seleccione Configuración > general >. En Métodos abreviados de teclado , seleccione la opción que desee y, a continuación, seleccione Guardar .
 En la Outlook en la Web clásica, seleccione > Correo > Métodos abreviados de teclado generales >. Seleccione la opción que desee y, a continuación, seleccione Guardar .
