el mismo para las 50 y pico ocupaciones tipo convocadas, así que las preguntas de
Constitución, Ley 17/2006, Convenio, Igualdad, Ley 13/2022, Ley 8/2009 y
prevención de riesgos de cualquiera de estos exámenes son material de calibración
para el bloque común.

Cómo se hicieron las transcripciones: capa de texto del PDF con `pdfminer`. El
cuadernillo de Documentación no la tiene —es un escaneo— y se pasó por OCR
(`tesseract`, español, 300 ppp); su `.txt` puede tener erratas de OCR, así que
para citar una pregunta suya hay que mirar el PDF.
