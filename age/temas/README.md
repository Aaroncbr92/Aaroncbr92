# Temas

Un fichero por tema, con el número del programa delante:
`NN-titulo-en-minusculas.md`. La portada y el índice de cada uno los genera
`herramientas/indice.py`, que los lee de `portadas.tsv`; no se escriben a mano.

Todavía no hay ninguno. El orden en que se van a escribir está en `../PLAN.md`.
