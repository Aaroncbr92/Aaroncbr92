# Abrir y buscar elementos en un archivo de datos de Outlook (.pst)

 Se aplica a
Outlook para Microsoft 365 Outlook 2024 Outlook 2021 Outlook 2019 Outlook 2016 Nuevo Outlook para Windows 

Los Outlook Data Files (.pst), o archivos de tablas de almacenamiento personal, contienen mensajes de usuario de Outlook y otros elementos de Outlook, como contactos, citas, tareas, notas y entradas de diario. También puede usar un archivo de datos de Outlook para hacer una copia de seguridad de mensajes o almacenar elementos antiguos localmente en su equipo para mantener reducido el tamaño del buzón.

Actualmente, ofrecemos diferentes niveles de compatibilidad para Outlook Data Files, en función de la versión de Outlook que use. Para determinar qué versión de Outlook está usando, busque la palabra Outlook en la barra de aplicaciones superior. Si solo ve el icono de Outlook, está usando Outlook clásico. Si el nombre del producto está junto al icono de Outlook, está usando el nuevo Outlook.

## Compatibilidad con archivos de datos de Outlook (.pst) en el nuevo Outlook

Puede mover, copiar y eliminar correos electrónicos y carpetas en el archivo .pst. También puede arrastrar y colocar correos electrónicos entre el buzón y los archivos .pst. La actualización más reciente ahora incluye la capacidad de exportar correos electrónicos, calendarios, contactos y tareas desde un buzón a un archivo .pst.

Tenemos previsto lanzar la compatibilidad para la importación masiva de Correo, Calendario y Contactos desde un PST a un buzón. También eliminaremos el requisito de que los usuarios tengan Outlook clásico instalado para usar PST en el nuevo Outlook. Después de eso, no tenemos más inversiones planeadas.

Para obtener más información, vea: Exportar correos electrónicos, contactos y elementos de calendario a Outlook con un archivo .pst.

### Abrir un archivo de datos de Outlook (.pst) en el nuevo Outlook

Puede abrir archivos .pst, leer correos electrónicos en archivos .pst y buscar correos electrónicos en archivos .pst.

- Para abrir un archivo de datos de Outlook (.pst), vaya a SettingsFilesOutlook>>Data Files.

- Seleccione Agregar archivo.

- Seleccione un archivo .pst y, a continuación, seleccione Abrir.

## Abrir un archivo de datos de Outlook (.pst) en Outlook clásico

Si usa una cuenta POP o IMAP, toda la información de Outlook se almacenan en un archivo de datos de Outlook, también conocido como un archivo de tabla de almacenamiento personal (.pst).

De forma predeterminada, al usar las herramientas de búsqueda de Outlook clásico, este solo busca en el buzón actual. A menos que cambie el ámbito de búsqueda a todos los buzones no se buscarán archivos de datos de Outlook adicionales almacenados en el equipo.

También es posible tener un archivo de datos de Outlook si elige Autoarchivar con su cuenta de correo electrónico de Exchange server. Esta es una característica diferente que el botón de archivar en Outlook 2016. Para obtener más información, vea Archivar en Outlook 2016. Para ver la ubicación y la configuración de Autoarchivar e instrucciones para desactivar Autoarchivar, vea Archivar elementos antiguos automáticamente.

## Abrir un archivo de datos de Outlook en Outlook clásico

Para que Outlook pueda buscar una palabra, frase o remitente en un archivo de carpetas personales, el archivo debe estar abierto en Outlook.

- En Outlook clásico, elija Abrir archivo>& Exportar>Abrir archivo de datos de Outlook.

- Elija el archivo de datos de Outlook que desee abrir.

- Expanda el nivel superior del archivo de datos de Outlook en el panel de navegación de Outlook para ver las subcarpetas del archivo. Haga clic en cada subcarpeta para ver el contenido.

- Para buscar un correo electrónico específico, use las herramientas de búsqueda integrada de Outlook.

- Si quiere importar los elementos archivados de nuevo a la Bandeja de entrada, siga las instrucciones para importar un archivo .pst.

### Buscar el archivo .pst

En Outlook 2016 y versiones más recientes, los nuevos archivos de datos de Outlook se guardan de forma predeterminada en las siguientes ubicaciones:

- Unidad deWindows 10:\Usuarios\usuario\Documentos\Outlook Files\archivo.pst

En versiones anteriores de Outlook: El archivo de almacenamiento se guarda en las siguientes ubicaciones:

- Unidad deWindows 10:\Usuarios\usuario\AppData\Local\Microsoft\Outlook\archivo.pst
