# Herramientas de administración remota del servidor (RSAT) para Windows

- Se aplica a: Supported versions of Windows Server

## 

RSAT permite a los administradores de TI administrar de forma remota roles y características en Windows Server desde un equipo que ejecuta Windows 10 y Windows 7 Service Pack 1.

 Número de KB original: 2693643

## Introducción

No puede instalar RSAT en equipos que ejecutan ediciones Home o Standard de Windows. Solo puede instalar RSAT en las ediciones Professional o Enterprise del sistema operativo cliente Windows. A menos que la página de descarga indique específicamente que RSAT se aplica a una versión beta, versión preliminar u otra versión previa de Windows, debe ejecutar una versión completa (RTM) del sistema operativo Windows para instalar y usar RSAT. Algunos usuarios han encontrado formas de descifrar o piratear manualmente el MSU de RSAT para instalar RSAT en versiones o ediciones no admitidas de Windows. Este comportamiento es una infracción de los términos de licencia de Windows.

La instalación de RSAT es similar a Adminpak.msi en equipos cliente basados en Windows 2000 o basados en Windows XP. Sin embargo, hay una diferencia importante: en Windows 7, las herramientas no están disponibles automáticamente después de descargar e instalar RSAT. Habilite las herramientas que desea usar mediante el Panel de control. Para habilitar las herramientas, seleccione Inicio>Panel de control>Programas y características y después Activar o desactivar las características de Windows.

En las versiones RSAT para Windows 10, las herramientas están de nuevo todas habilitadas de forma predeterminada. Puede abrir Activar o desactivar las características de Windows para deshabilitar las herramientas que no desea usar para Windows 7.

Para RSAT en Windows 7, debe habilitar las herramientas para los roles y características que desea administrar después de ejecutar el paquete de instalación descargado.

Nota:

No puede realizar los siguientes cambios para RSAT en Windows 8 o versiones posteriores.

Si tiene que instalar herramientas de administración en Windows Server 2012 R2 para roles o características específicos que se ejecutan en servidores remotos, no tiene que instalar software adicional. Inicie el Asistente para agregar roles y características en Windows Server 2012 R2 y versiones posteriores. A continuación, en la página Seleccionar características, expanda Herramientas de administración remota del servidor y luego seleccione las herramientas que desea instalar. Complete el asistente para instalar las herramientas de administración.

## RSAT para Windows 10, versión 1809 o posterior

Nota:

No puede usar el cuadro de diálogo Activar y desactivar características de Windows desde el Panel de control.
Para Windows 11, versión 25H2 en dispositivos basados en Arm64, acceda a algunas de las herramientas de RSAT; para ello, vaya a Programasy características> del Panel>> de controlActivar o desactivar características de Windows.
Los complementos RSAT disponibles actualmente en Arm64 son RSAT: Active Directory Domain Services y Herramientas ligeras de Servicios de directorio, RSAT: Herramientas de Servicios de certificados de Active Directory, RSAT: Administrador del servidor, RSAT: Herramientas de administración de directivas de grupo, RSAT: Herramientas de servidor DNS y RSAT: Herramientas del servidor DHCP.

La instalación de las herramientas RSAT para Windows 10, versión 1809 y posteriores es ligeramente diferente de las versiones anteriores. RSAT forma ahora parte del sistema operativo y se puede añadir a través de Características opcionales.

Para habilitar las herramientas, seleccione Inicio>Configuración>Aplicaciones (si usa Windows 10, versión 22H2 o versiones posteriores, seleccione Sistema en su lugar) y después seleccione Características opcionales. Después, seleccione el panel Agregar una característica y escriba Remoto en la barra de búsqueda.
