# ¿Qué es la opción de instalación Server Core en Windows Server?

- Se aplica a: ✅ Windows Server 2025, ✅ Windows Server 2022, ✅ Windows Server 2019, ✅ Windows Server 2016, ✅ Windows 11, ✅ Windows 10

## 

La opción Server Core es una opción de instalación mínima que está disponible al implementar la edición Standard o Datacenter de Windows Server. Server Core incluye la mayoría de los roles de servidor, pero no todos. Server Core tiene una superficie de disco más pequeña y, por tanto, una superficie de ataque más pequeña debido a una base de código menor.

## Server (Core) frente a Server con Experiencia de escritorio

Al instalar Windows Server, solo se instalan los roles de servidor que elija. La instalación solo de los roles necesarios ayuda a reducir la huella general de Windows Server. Sin embargo, la opción de instalación Servidor con experiencia de escritorio sigue instalando muchos servicios y otros componentes que a menudo no necesita para un escenario de uso determinado.

La instalación de Server Core elimina los servicios y otras características que no son esenciales para la compatibilidad de determinados roles de servidor usados habitualmente. Por ejemplo, un servidor de Hyper-V no necesita una interfaz gráfica de usuario (GUI), ya que se pueden administrar prácticamente todos los aspectos de Hyper-V desde la línea de comandos mediante Windows PowerShell o de forma remota mediante el Administrador de Hyper-V.

## La diferencia de Server Core: funcionalidades principales sin excesos

Cuando termine de instalar Server Core en un sistema e inicie sesión por primera vez, tendrá una pequeña sorpresa. La principal diferencia entre la opción de instalación Servidor con experiencia de escritorio y Server Core es que Server Core no incluye los siguientes paquetes de shell de GUI:

- `Microsoft-Windows-Server-Shell-Package`

- `Microsoft-Windows-Server-Gui-Mgmt-Package`

- `Microsoft-Windows-Server-Gui-RSAT-Package`

- `Microsoft-Windows-Cortana-PAL-Desktop-Package`

En otras palabras, no hay escritorio en Server Core, por diseño. Aunque se mantienen las funcionalidades necesarias para admitir aplicaciones empresariales tradicionales y cargas de trabajo basadas en roles, Server Core no tiene una interfaz de escritorio tradicional. En su lugar, administra Server Core de forma remota a través de la línea de comandos, PowerShell, una herramienta de GUI como RSAT o Windows Admin Center.

Además de no haber UI, Server Core también difiere de Server con Experiencia de escritorio en lo siguiente:

- Server Core no tiene ninguna herramienta de accesibilidad

- No hay OOBE (experiencia lista para usar) para configurar Server Core

- No hay compatibilidad de audio

- Los servicios de notificaciones push de Windows (WpnService y WpnUserService) no están instalados. Las notificaciones push para aplicaciones para la Plataforma universal de Windows (UWP) y la funcionalidad del Servicio de notificaciones push de Microsoft (MPNS) no se admiten en Server Core, ya que se basan en componentes de experiencia de escritorio (shell de GUI y tiempo de ejecución de UWP).

 Importante: En la mayoría de los casos, puede ejecutar aplicaciones que aparecen como "no disponibles" de forma remota desde un equipo cliente windows o Windows Admin Center para administrar la instalación de Server Core.

### Funcionalidad a demanda para ubicaciones de descarga de Server Core

Puede obtener paquetes posteriores de características de Windows Server a petición (FoD) desde el Centro de licencias de MS específico si tiene Software Assurance activo. Necesita una cuenta profesional o educativa de Microsoft inscrita en VLSC o Business Center para acceder a la descarga de FoD.

Como alternativa, es posible que tenga acceso a una suscripción de Visual Studio. Necesita una cuenta de Microsoft Home, Work o School, inscrita en una suscripción activa de Visual Studio, para acceder a la descarga de FoD.

Puede descargar la versión más reciente de Server Insider FoD en la página web de Server Insider. Necesita una cuenta de Microsoft Home, Work o School, inscrita en el Programa Insider, para acceder a la descarga de FoD.
