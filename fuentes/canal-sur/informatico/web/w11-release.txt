# Información de versión de Windows 11

## 

Windows 11 tiene una cadencia de actualización de características anual. Las actualizaciones de características se publican en la segunda mitad del año natural y cuentan con 24 meses de soporte técnico para las ediciones Home, Pro, Pro for Workstations y Pro Education. 36 meses de soporte técnico para las ediciones Enterprise y Education. Para obtener más información, consulte las Preguntas más frecuentes sobre el ciclo de vida de Windows.

Windows 11 también publica actualizaciones de seguridad mensuales el segundo martes de cada mes. Estas versiones son acumulativas y contienen todas las actualizaciones anteriores para mantener los dispositivos protegidos y productivos.

Si es administrador de TI y desea obtener información de esta página mediante programación, use la API de actualizaciones de Windows en Microsoft Graph.

Note

Windows 11, versión 26H1 tiene como ámbito admitir nuevos dispositivos que empezaron a comercializarse a principios de 2026 y no está diseñado como una actualización de características para dispositivos existentes. Esta versión no se ofrece como una actualización local de 24H2 o 25H2 en dispositivos existentes.

## Historial de versiones de Windows 11

Consulta el historial de todas las actualizaciones mensuales de seguridad y no de seguridad publicadas para Windows 11. Ten en cuenta que la columna Tipo de actualización hace referencia a cada actualización mensual por el año y el mes de su lanzamiento, seguido de una letra que indica la semana del mes (B es la segunda semana del mes; D es la cuarta semana del mes). Las actualizaciones fuera de banda se denominan OOB. Esta notación abreviada coincide con lo que se ve en Microsoft Intune. Para obtener más información, consulta Tipo de versiones de actualización.

Visita el historial de actualizaciones de Windows 11 para obtener información detallada sobre el contenido de cada versión.

## Calendario de revisiones en caliente de Windows 11

Ver un calendario de actualizaciones de revisiones de acceso frecuente para Windows 11. Con la aplicación de revisiones en caliente, los dispositivos reciben una actualización acumulativa de línea base el primer mes de cada trimestre del año natural. Se requiere un reinicio para instalar esa actualización de línea base. En los meses restantes, los dispositivos reciben una actualización de revisiones en caliente, que solo incluye actualizaciones de seguridad y se puede instalar sin reiniciar. Para obtener más información sobre lo que se incluye en cada actualización, consulte las notas de la versión de revisión en Windows 11, versión 26H2, versión 25H2y versión 24H2.

Note

La aplicación de revisiones en caliente no está disponible en Windows 11, versión 26H1.
