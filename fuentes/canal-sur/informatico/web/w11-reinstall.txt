Los medios de instalación para Windows son una herramienta versátil que sirve para múltiples propósitos, incluidas las instalaciones locales para recuperación y nuevas instalaciones. Este medio, que normalmente se crea en una unidad USB o en un DVD, contiene todos los archivos necesarios para instalar o reinstalar Windows en el dispositivo. Es especialmente útil en situaciones en las que el sistema se encuentra con problemas importantes, como daños en el software o errores de hardware, que impiden que arranque o funcione correctamente.

Con fines de recuperación, el medio de instalación le permite realizar una instalación local, que básicamente reinstala Windows sin afectar a los archivos personales, la configuración ni las aplicaciones instaladas. Este método es ideal para resolver problemas del sistema a la vez que conserva los datos y las configuraciones. Arrancando desde el medio de instalación y seleccionando las opciones de recuperación adecuadas, puede restaurar el sistema a un estado estable sin necesidad de un borrado completo.

En los casos en que se requiera un comienzo de cero, los medios de instalación se pueden usar para una nueva instalación de Windows. Este proceso implica borrar completamente los datos existentes en el dispositivo e instalar una versión limpia de Windows. Es una opción adecuada cuando desea eliminar todos los datos, configuraciones y aplicaciones anteriores, o al configurar un nuevo dispositivo.

## Alternativas a la reinstalación con medios

Antes de reinstalar Windows con el soporte de instalación, consulte el artículo Opciones de recuperación en Windows, que proporciona una descripción general de las distintas soluciones para recuperar Windows.

## Antes de iniciar la reinstalación

## Comprobar el espacio en disco

Si un dispositivo no funciona según lo esperado o Windows tiene problemas, puede deberse a que hay poco espacio en disco. Antes de reinstalar Windows, intenta liberar espacio en disco para ver si se resuelven los problemas. Para obtener más información, consulta Liberar espacio en unidades de disco en Windows.

## Realizar una copia de seguridad de los datos

Si es necesario guardar datos y archivos personales antes de reinstalar Windows, haz una copia de seguridad de ellos antes de realizar la reinstalación. Se puede hacer una copia de seguridad de los datos personales y los archivos en un disco duro externo, en una unidad flash USB o en una ubicación en la nube, como OneDrive.

## Asegúrate de que Windows esté activado

Windows debe activarse después de reinstalarlo. Por lo general, la activación se realiza automáticamente después de conectarse. Para obtener más información, consulta Activar después de reinstalar Windows.

## Vincule la licencia digital a su cuenta de Microsoft

Para poder reactivar Windows después de una reinstalación de Windows, su cuenta de Microsoft debe estar vinculada a la licencia digital de Windows en el dispositivo. Para obtener más información, consulte Vincular la licencia digital de Windows a su cuenta de Microsoft.

## Es necesario volver a activar Windows si se realiza un cambio de hardware significativo en el dispositivo

Si se vuelve a instalar Windows después de realizar un cambio de hardware importante en el dispositivo (como reemplazar la placa base), es posible que ya no esté activado. El Solucionador de problemas de activación se puede usar para reactivar Windows. Para obtener más información, consulte Uso del Solucionador de problemas de activación.

## La edición de Windows que se va a reinstalar debe coincidir con la licencia

Al reinstalar Windows, seleccione la edición de Windows que coincida con su licencia digital. Por ejemplo, si la edición actual de Windows es Home, Windows Home debe instalarse de nuevo.

### Instalación limpia

Si el equipo no se inicia y no tienes una unidad de recuperación o un disco de reparación, puedes usar la Herramienta de creación de medios para crear medios de instalación para Windows. Esta herramienta se puede usar para descargar la versión más reciente de Windows y crear una unidad USB o DVD de arranque, que se puede usar para realizar una instalación limpia de Windows.

Advertencia

Una instalación limpia es una opción avanzada para ayudar a empezar de cero en un dispositivo. Microsoft recomienda seguir los pasos siguientes solo si está seguro de realizar estos cambios. Para obtener más ayuda, póngase en contacto con el servicio de soporte técnico. Una instalación limpia elimina todos los elementos siguientes:

- Archivos personales

- Aplicaciones

- Personalizaciones del fabricante del dispositivo

- Cualquier cambio realizado en la Configuración
