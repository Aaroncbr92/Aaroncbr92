La Fábrica Nacional de Moneda y Timbre ha desarrollado esta aplicación para solicitar las claves necesarias en la obtención de un certificado digital. Puede ser ejecutada en cualquier navegador y sistema Operativo.
Descargue e instale el software necesario para su sistema operativo.
Los antivirus y proxies pueden impedir el uso de esta aplicación, por favor no utilice proxy o permita el acceso a esta aplicación en su proxy.
WINDOWS
Configurador FNMT-RCM para Windows 64 bits
MAC
Configurador FNMT-RCM para MacOS
Si al instalar en MacOS aparece un mensaje indicando que no se puede instalar el software por proceder de un desarrollador no identificado debe ir a Preferencias del sistema / Seguridad y Privacidad / Pestaña GENERAL, en la sección Permitir apps descargadas de, debe permitir la ejecución de la aplicación para que continúe el proceso de instalación. En MacOS Ventura debe de ir a Ajustes del sistema > Privacidad y Seguridad > apartado de Seguridad aparecerá la opción de permitir apps descargadas.
MAC con chip M  ¿Cómo puedo comprobar qué chip tiene mi MAC?

Descarga de software
Aquí encontrarás el software necesario para utilizar certificados digitales y tarjetas criptográficas.
Antes de empezar
Comprueba tu sistema operativo (Windows, Mac o Linux).
Si usas tarjeta criptográfica, necesitarás instalar software adicional.
Generación de claves (obligatorio)
Este paso es imprescindible.
Para poder solicitar y obtener tu certificado digital es necesario generar previamente un par de claves en tu equipo.
Sin este software no podrás completar la solicitud del certificado.
Utiliza el Configurador de la FNMT-RCM para generar las claves de forma segura antes de iniciar el trámite en la Sede electrónica.
Descargar Configurador FNMT-RCM para la generación de claves
Certificados en tarjeta criptográfica
Windows
La FNMT-RCM ha desarrollado un Instalable que integra todos los elementos necesarios para el funcionamiento de los Certificados de Usuario en Tarjeta. Los elementos que se instalan son:
Software adicional para certificados de usuario en tarjeta criptográfica. (Requiere Java v.8 Update 45 hasta Java 15)
Módulo PKCS#11, para trabajar en Mozilla.
Módulo Smart Card Minidriver para Windows.
Pulsa en el enlace correspondiente dependiendo de si tu Sistema Operativo es de 32 o de 64 bits. Para su correcto funcionamiento descarga el ejecutable en tu ordenador, cierra los navegadores, haz clic sobre el mismo con permisos de administrador e instala el programa.
Instalador Tarjeta TC-FNMT para 32 bits (Versión 2.0.0 ; EXE - 24,7 MB)
Instalador Tarjeta TC-FNMT para 64 bits (Versión 2.0.0 ; EXE - 27,5 MB)
Si necesitas ayuda para la instalación, descarga el siguiente Manual de Instalador Tarjeta TC-FNMT Dnie .
Asimismo, tienes a tu disposición el Historial de versiones de TC-FNMT para Windows .

Herramientas adicionales para Certificados en tarjeta criptográfica (Windows / Mac / Linux)
Estas utilidades permiten gestionar certificados almacenados en la tarjeta.
Importante:
Windows: requiere Java 8 hasta Java 15
Mac Intel: requiere librería MultiCard
Mac ARM (M1/M2): requiere Java 11
Gestión de certificados en tarjeta
Ver certificados
Importar copias de seguridad
Cambiar o desbloquear el PIN
Windows: Descargar Utilidad para la Gestión de Certificados  (versión 1.4.0.8 ; ZIP - 53,5 MB)
Mac / Linux: Descargar Utilidad para la Gestión de Certificados  (versión 1.4.0.8 ; ZIP – 8,08 MB)
Eliminar certificados antiguos
Permite borrar certificados antiguos si existen varios en la tarjeta.
Windows: Descarga del Software de Eliminación de Certificado  (ZIP - 7,4 MB)
Mac: Descarga del Software de Eliminación de Certificado  (ZIP - 7,4 MB)
Eliminar claves sin certificado
Elimina claves que no están asociadas a ningún certificado, tanto públicas como privadas.
Windows: Descarga Actualizador de Claves. (ZIP - 7,4 MB)
Mac: Descarga Actualizador de Claves. (ZIP - 7,4 MB)
Formatear tarjeta
Restablece la tarjeta criptográfica a estado de fábrica.
Windows: Descarga Formatear Tarjeta (ZIP -  7,4 MB)
Mac: Descarga Formatear Tarjeta (ZIP -  7,4 MB)
