# ¿Qué es la aplicación Windows?

## 

La aplicación windows se conecta de forma remota a los dispositivos y aplicaciones de Windows desde Azure Virtual Desktop, equipos en la nube de Windows 365, Microsoft Dev Box, Servicios de Escritorio remoto y equipos, lo que le conecta de forma segura a dispositivos y aplicaciones Windows.

Puedes utilizar Aplicación de Windows en muchos tipos diferentes de dispositivos en diferentes plataformas y factores de forma, como equipos de escritorio y portátiles, tabletas, smartphones y mediante un explorador web. Si se conecta mediante un explorador web en un equipo de escritorio o portátil, puede conectarse sin tener que descargar e instalar ningún software.

Aplicación de Windows está disponible para las siguientes plataformas:

- Windows

- macOS

- iOS/iPadOS

- Sistema operativo Android/Chrome

- Exploradores web

- Casco vr de Meta Quest

Nota:

Solo tiene que iniciar sesión en la aplicación de Windows para conectarse a Azure Virtual Desktop, equipos en la nube de Windows 365, Microsoft Dev Box, Servicios de Escritorio remoto. En el caso de las plataformas que admiten conexiones remotas de PC, puede usar la aplicación de Windows sin iniciar sesión.

Iniciar sesión requiere una cuenta profesional o educativa de Microsoft proporcionada por el administrador. No puede iniciar sesión en la aplicación de Windows con una cuenta Microsoft (MSA) personal.

## Características

Aplicación de Windows está diseñada con una pantalla de inicio personalizable para satisfacer tus necesidades únicas de flujo de trabajo. Puede acceder a Windows a través de varios servicios y equipos remotos desde un solo lugar y anclar los favoritos a los que más accede. Y si usas varias cuentas, puedes cambiar fácilmente entre ellas con nuestra sencilla característica de cambio de cuenta.

Hay muchas características que puedes usar para mejorar la experiencia remota, como:

- Compatibilidad con varios monitores.

- Resoluciones de visualización personalizadas.

- Resoluciones de visualización y escalado dinámicos.

- Redirección de dispositivos, como cámaras web, audio, dispositivos de almacenamiento e impresoras.

- Optimizaciones de Microsoft Teams.

- Inicia sesión con varias cuentas y cambia fácilmente entre ellas.
