# Recuperación de archivos de Windows

 Se aplica a
Windows 11 Windows 10 

Nota

 El soporte técnico para Windows 10 finalizó el 14 de octubre de 2025

- Después del 14 de octubre de 2025, Microsoft ya no proporcionará actualizaciones de software gratuitas desde Windows Update, asistencia técnica ni correcciones de seguridad para Windows 10. El PC seguirá funcionando, pero recomendamos que se cambie a Windows 11.

- 
 Más información

Si no puedes encontrar un archivo perdido en la copia de seguridad, puedes usar Windows File Recovery, que es una aplicación de línea de comandos disponible en Microsoft Store. Usa esta aplicación para intentar recuperar los archivos perdidos que se han eliminado del dispositivo de almacenamiento local (incluidas las unidades internas, unidades externas y dispositivos USB) y no se puede restaurar desde la Papelera de reciclaje. No se admite la recuperación en recursos compartidos de archivos y almacenamiento en la nube.

Importante

Si quieres aumentar las posibilidades de recuperar un archivo, minimiza o evita usar el equipo. En el sistema de archivos de Windows, el espacio usado por un archivo eliminado se marca como espacio libre, lo que significa que los datos del archivo aún pueden existir y recuperarse. Sin embargo, cualquier uso de su equipo puede crear archivos, lo que puede sobrescribir este espacio libre en cualquier momento.

## Pasos básicos

- 
Si es necesario, instala la aplicación desde Microsoft Store:

 Recuperación de archivos de Windows

- 
Presiona la tecla Windows, escribe Windows File Recovery en el cuadro de búsqueda y, a continuación, selecciona Windows File Recovery.

- 
Cuando se te pida que permitas que la aplicación realice cambios en el dispositivo, selecciona Sí.

- 
En la ventana Símbolo del sistema , escriba el comando con el siguiente formato:

winfr source-drive: destination-drive: [/mode] [/switches]

- 
Hay 2 modos básicos que puede utilizar para recuperar archivos: Regular y Extenso.

 Ejemplos de modo normal

Recupera la carpeta Documentos desde la unidad C: a la carpeta de recuperación en una unidad E:. No olvide la barra diagonal inversa (\) al final de la carpeta.

Winfr C: E: /regular /n \Users\<username>\Documents\ 

Recupera archivos PDF y Word desde la unidad C: a la carpeta de recuperación en una unidad E:.

Winfr C: E: /regular /n *.pdf /n *.docx 

 Ejemplos de modo extensivo

Recupere cualquier archivo con la cadena "factura" en el nombre de archivo usando caracteres comodín.

Winfr E: C: /extensive /n *invoice* 

Recupera fotos jpeg y png desde la carpeta Imágenes a la carpeta de recuperación en una unidad E:.

Winfr C: E: /extensive /n \Users\<username>\Pictures\*.JPEG /n\Users\<username>\Pictures\*.PNG 

Las unidades de origen y destino deben ser diferentes. Al recuperar desde la unidad del sistema operativo (a menudo C: ), usa los /n <filter> modificadores para especificar los archivos de usuario o la carpeta.

Microsoft crea automáticamente una carpeta de recuperación para la que has llamado, Recovery_<date and time> en la unidad de destino.

- 
Cuando se le pida confirmación para continuar, escriba Y para iniciar la operación de recuperación. Dependiendo del tamaño de la unidad de origen, esto puede tardar un rato. Para detener el proceso de recuperación, presione Ctrl + C.

## Preguntas frecuentes

 ¿Puede dar algunos consejos para ayudarme a usar la sintaxis correcta?

- Use siempre letras de unidad en la ruta de origen y destino, no olvide los dos puntos (:) después de la letra de unidad y asegúrese de que hay un espacio entre el origen y el destino.

- Cuando especifique solo un nombre de carpeta, como /n \Myfolder\, agregue una barra diagonal inversa (\) al final de la misma.

- Si el nombre de un archivo o carpeta tiene espacios, indíquelo entre comillas. Por ejemplo:

winfr C: E: /regular /n "\Users\<username>\Documents\Quarterly Statement.docx" 

 <¿Qué significa nombre de usuario> en los ejemplos de comandos?

En la barra de direcciones Explorador de archivos, escriba C:\usuarios para ver una lista de posibles usuarios en el equipo. Puede haber varios usuarios en el equipo, incluidos usted, el administrador y la cuenta predeterminada. Cuando ve <el nombre de usuario> en una ruta de acceso de archivo, es un marcador de posición para el nombre de usuario actual en el equipo.

 ¿Por qué recibo este mensaje: "El origen y el destino no pueden hacer referencia a la misma partición física?"

La ruta de origen y destino de la unidad o partición no debe ser la misma. Si solo tienes una unidad, usa una unidad de disco duro USB o externa como ruta de destino. No crees una partición después de perder datos, ya que esto reduce la posibilidad de una recuperación correcta.

 ¿Por qué tarda tanto la operación de recuperación?

Dependiendo del tamaño del disco, puede tardar algún tiempo en recuperar el archivo, especialmente si está utilizando el modo extenso.

 ¿Por qué se recuperan archivos adicionales de la unidad del sistema operativo?

En segundo plano, Windows crea y elimina constantemente archivos. De forma predeterminada, Windows File Recovery filtra estos archivos, pero algunos se deslizan. Para evitar esto, use el filtro> /n <como se muestra en los ejemplos de este artículo.

 ¿Cuál es la carpeta $Recycle.Bin?

Para los modos NTFS y de segmento, también puedes ver archivos perdidos recuperados de la Papelera de reciclaje (archivos en la Papelera de reciclaje o que se eliminaron permanentemente) con el nombre $files.xxx y almacenados en una carpeta denominada $RECYCLE. BIN.

 ¿Qué sucede si la unidad de destino está llena?

Si ves el siguiente mensaje: "El disco de destino está lleno, libera espacio antes de reanudar: (R)esume, (S)kip file, o (A)bort", libera espacio en la unidad de disco de destino y, a continuación, elige una de las opciones.

 No pude recuperar el archivo, ¿y ahora qué?

Si ha usado el modo Regular, inténtelo de nuevo en modo extenso si el tipo de archivo es compatible. Es posible que el espacio libre se sobrescriba, especialmente en una unidad de estado sólido (SSD). Si necesita ayuda, póngase en contacto con el administrador.
