# Información de versión de Windows Server

## 

Windows Server tiene dos canales de lanzamiento principales: el Canal de mantenimiento a largo plazo y el canal anual. El LTSC ofrece una opción a más largo plazo centrada en un ciclo de vida tradicional de actualizaciones de seguridad y calidad. El AC proporciona lanzamientos más frecuentes, centrados en contenedores y microservicios, para que pueda aprovechar la innovación con mayor rapidez.

Windows Server 2025 es la versión de LTSC actual. Windows Server, versión 23H2 es la última versión de AC. El enfoque en la innovación de virtualización, contenedor y microservicio continúa con Azure Stack HCI, contenedores de Windows y AKS en Azure Stack HCI.

Si es administrador de TI y desea obtener información de esta página mediante programación, use la API de actualizaciones de Windows en Microsoft Graph.

## Historial de versiones de Windows Server

La siguiente tabla muestra el historial de todas las actualizaciones mensuales de seguridad y no de seguridad publicadas para las versiones compatibles de Windows Server en el Canal de servicio a largo plazo. 

Ten en cuenta que la columna Tipo de actualización hace referencia a cada actualización mensual por el año y el mes de su publicación, seguidos de una letra que indica la semana del mes (B es la segunda semana del mes; D es la cuarta semana del mes). Las actualizaciones fuera de banda se denominan OOB. Esta notación abreviada coincide con lo que se ve en Microsoft Intune. Para obtener más información, consulta Tipo de versiones de actualización.

Las notas de la versión de Windows Server están disponibles en el historial de actualizaciones de Windows Server 2025, el historial de actualizaciones de Windows Server 2022, el historial de actualizaciones de Windows Server 2019 y el historial de actualizaciones de Windows Server 2016.

## Calendario de revisiones en caliente de Windows Server

Visualiza un calendario de revisiones en caliente para Windows Server 2025 y Windows Server 2022. Con las revisiones en caliente, los dispositivos reciben una actualización acumulativa de línea de base el primer mes de cada trimestre del año natural. Es necesario reiniciar el sistema para instalar la actualización. Durante los dos meses siguientes, los dispositivos recibirán una revisión en caliente, que solo incluye actualizaciones de seguridad y puede instalarse sin reiniciar.
