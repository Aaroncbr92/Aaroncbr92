 | Límites máximos de almacenamiento en memoria y tamaños de archivos para libros del modelo de datos

 | El entorno de 32 bits está sujeto a una limitación de 2 gigabytes (GB) de espacio de direcciones virtuales, compartido por Excel, el libro y los complementos que se ejecuten en el mismo proceso. La parte de dirección del modelo de datos podría alcanzar de 500 a 700 megabytes (MB), pero podría ser inferior si se cargan otros modelos de datos y complementos.

El entorno de 64 bits no impone límites estrictos al tamaño del archivo. El tamaño del libro está limitado solo por la memoria disponible y los recursos del sistema.

A partir de Excel 2016, la función Detección de direcciones largas permite que Excel de 32 bits consuma el doble de memoria cuando los usuarios trabajan en un sistema operativo Windows de 64 bits. Para obtener más información, consulte Cambio de funcionalidad según detección de direcciones grandes para Excel.

 Nota: Agregar tablas al modelo de datos aumenta el tamaño de archivo. Si no tiene previsto crear relaciones del modelo de datos complejas usando numerosos orígenes de datos y tipos de datos en su libro, desactive la casilla Agregar estos datos al modelo de datos al importar o crear tablas, tablas dinámicas o conexiones de datos. Para obtener más información, consulte Especificación y límites del modelo de datos.

## Libros con la configuración "Permitir que más de un usuario pueda hacer cambios..." activada

Si la configuración Permitir que más de un usuario pueda hacer cambios... está activada para un libro, se aplica la siguiente información. Para acceder a esta configuración, haga clic en la pestaña >Revisary Compartir libro. Tenga en cuenta que, en la versión más reciente de Excel, el botón Compartir libro se ha ocultado. Para mostrarlo, haga clic enBarra de herramientas de acceso rápidoOpciones> de archivo>. Abra la lista Elegir comandos de y seleccione Todos los comandos. Desplácese por esa lista hasta que vea Compartir libro (heredado). Seleccione dicho elemento y haga clic en Agregar. Haga clic en Aceptar. El botón Compartir libro ahora se encuentra en la parte superior de la ventana de Excel.
